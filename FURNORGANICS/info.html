Order Info

This page explains how pickup, shipping, receipts, and verification work.

Pickup Orders

Pickup orders use the basic checkout form. After submitting an order, the customer receives a receipt email with the order ID.

Shipping Orders

Shipping orders require a street address, state, and zip code. After submitting, the order is reviewed and instructions are sent by email.

Product Verification

Use the Verify Product page to enter a code and check if it matches the valid-codes.json file.
